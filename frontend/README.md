# SkillBridge Frontend

SkillBridge is a professional skill and service marketplace where users can connect with people who offer professional skills and services.

This repository contains the frontend application built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- User registration
- Normal User and Pro User account types
- User login
- Password recovery
- Responsive design
- Dark-mode interface
- Professional profile pages
- Skill and service marketplace
- Service requests
- User reviews and ratings
- Responsive navigation
- Mobile, tablet, and desktop support

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- ESLint
